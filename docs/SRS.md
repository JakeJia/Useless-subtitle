## 1. 引言 (Introduction)

### 1.1 编写目的
本文档明确“Useless Subtitle”字幕遮罩工具的产品需求、系统边界、交互逻辑与非功能指标，为技术选型、架构设计及自动化测试提供规范依据。

### 1.2 术语表 (Glossary)
| 术语 | 英文 / 别名 | 说明 |
| :--- | :--- | :--- |
| **置顶** | Topmost / Always on Top | 窗口在操作系统窗口层级中保持最高优先级，不被其他普通窗口覆盖。 |
| **鼠标穿透** | Click-through / Pass-through | 遮罩窗口忽略所有鼠标点击/滚轮事件，将事件直接传递给遮罩下方的应用（如浏览器视频播放器）。 |
| **锁定模式** | Lock Mode | 遮罩进入固定状态，禁止拖动和变形，并开启鼠标穿透。 |
| **系统托盘** | System Tray / Menu Bar | Windows 任务栏右下角 notification area 或 macOS 顶部 Menu Bar 的小图标。 |
| **DPI 感知** | High DPI Awareness | 适配高分辨率屏幕缩放（如 125%, 150%, 200%），防止界面模糊或坐标偏移。 |
| **工具窗口** | ToolWindow / Utility Window | 操作系统级别的特殊窗口，不在任务栏和 Alt+Tab 切换列表中显示。 |

### 1.3 产品范围
本项目是一款轻量级桌面端实用工具。主要用于用户在观看在线视频（如 Bilibili、YouTube）或播放本地视频时，在屏幕上叠加一个或多个可自定义的置顶遮罩层，用以遮挡视频画面中不需要的字幕（如中英双语字幕中的中文字幕），以提供专注的外语学习或无干扰观影环境。

  1. 用户在浏览器打开 Bilibili / YouTube 播放英文原声视频，视频带有中文字幕。
  2. 启动本工具，拖动遮罩层精准覆盖中文字幕区域，右键点击遮罩调节适当透明度/颜色。

## 3. 功能需求 (Functional Requirements)

### 3.1 遮罩窗口与外观控制 (Mask Window & Appearance)
* **3.1.1 无边框置顶**: 遮罩窗口必须没有任何系统原生标题栏，并且保持最高置顶级别 (`Topmost`)。
* **3.1.2 存在感边界 (Window Presence)**: 遮罩窗口必须设定为“工具窗口 (`ToolWindow` 或相关属性)”，强制**从操作系统任务栏和 Alt+Tab 切换列表中隐藏**。工具的唯一常驻交互入口是系统托盘。
* **3.1.3 颜色与透明度调节**:
  * **颜色**: 支持常用颜色预设（黑、白、灰色、半透明灰）以及调色板自定义 HEX/RGB。
  * **透明度 (Opacity)**: 支持 10% - 100% 透明度调节，步进间隔为 10%。
  * **推荐默认值**: 纯黑色 (`#000000`)，不透明度 `90%`。
* **3.1.4 视觉细节**:
  * 四角进行优雅的圆角处理，提升视觉质感。

### 3.2 交互与尺寸调整 (Drag, Resize & Edge Cases)
* **3.2.1 自由拖拽与变形**: 
  * 在【解锁/编辑状态】下，鼠标左键按住遮罩内部即可移动；按住边框可单向拖动扩展，四角部位拖住可双方向拖动拓展。
  * 鼠标移动到遮罩边缘/四角时显示对应的调整手势指针。
* **3.2.2 最小尺寸与防丢失保护**:
  * **最小尺寸限制**: `50px x 20px`，防止缩得太小导致无法操作。
  * **防丢失逻辑**: 启动时校验上次保存的坐标是否处于当前连通的显示器有效区域内。若超出范围，自动重置到主显示器中央。

### 3.3 锁定模式与鼠标穿透 (Click-through / Lock Mode) **[核心关键]**
* **3.3.1 状态切换逻辑与底层物理悖论**:
  * **底层技术约束**：当窗口触发鼠标穿透（如 `ignoresMouseEvents`）时，该窗口将不再接收任何鼠标事件，因此**在穿透状态下无法通过点击窗口上的按钮来解锁**。
  * **正确状态机**：
    ```
    [编辑状态 (Editable)]  <---(仅限托盘菜单解锁)--->  [锁定/穿透状态 (Locked)]
    - 可拖拽/调整大小                                - 无法拖拽/变形
    - 拦截鼠标事件，可右键调出该遮罩设置                - 鼠标事件完全穿透到底层网页
    - 右上角显示 🔒(锁定) 和 ❌(关闭) 悬浮按钮           - 隐藏所有 UI 元素，仅保留纯色遮罩
    ```
* **3.3.2 穿透与解锁机制**:
  * 为避免与用户日常应用/游戏的快捷键产生严重的国际化冲突（如 `Alt+L` 冲突），**完全放弃绑定默认的全局字母快捷键**。
  * **唯一解锁途径**: 必须通过**右键点击系统托盘图标**，在菜单中选择“解锁全部遮罩”或解锁特定遮罩。

### 3.4 状态持久化与安全启动 (Persistence & Safe Boot)
* **3.4.1 配置即时保存**:
  * 不仅在退出时保存，在**每次拖拽结束、调整大小结束或颜色修改后**，即时保存配置至本地 JSON（防崩溃丢失）。
    * 各遮罩的位置 (`x`, `y`)、尺寸 (`width`, `height`)
    * 颜色 (`color`)、透明度 (`opacity`)
* **3.4.2 安全重载边界 (Safe Boot)**: 
  * 危险场景：若保存了“纯黑色+锁定”退出，下次启动时屏幕会出现无法点击的“黑块”，用户可能误以为显示器损坏。
  * **安全启动强制逻辑**：每次重新启动软件时，忽略配置文件中的“锁定”状态，**所有加载的遮罩强制重置为【解锁/编辑状态】**，方便用户确认位置，随后由用户自行决定是否锁定。

### 3.5 多遮罩实例支持 (Multi-Mask Support)
* **需求描述**: 支持在屏幕上同时创建与管理多个独立的遮罩层（如同时遮挡顶部弹幕/提示和底部中文字幕）。
* **多遮罩交互盲区与解决**:
  * **关闭特定遮罩**：在【解锁/编辑状态】下，遮罩右上角显示独立的 `❌` 悬浮关闭按钮。
  * **设置特定遮罩**：在【解锁/编辑状态】下，允许用户**右键点击特定的遮罩自身**，弹出独立的局部设置菜单（修改该遮罩的颜色、透明度）。托盘菜单仅用于全局控制。

## 4. 用户界面与控制交互 (UI / UX Control)

### 4.1 控制交互入口设计 (双通道管理)
控制逻辑被明确拆分为“局部交互”与“全局交互”：

1. **局部交互（针对特定遮罩，仅限【编辑状态】有效）**:
   - **内置悬浮按钮**: 遮罩右上角配备 `🔒` (锁定当前遮罩，并进入穿透) 和 `❌` (销毁当前遮罩)。
   - **右键上下文菜单**: 在遮罩内部右键点击，弹出调色板与 10%~100% 透明度调节项。

2. **全局交互（系统托盘 System Tray，始终有效）**:
   - **左键点击**: 一键隐藏 / 显示所有遮罩。
   - **右键菜单项**:
     - 新建遮罩窗口 (`New Mask`)
     - **解锁所有遮罩 (`Unlock All`)** - 这是穿透状态下唯一的恢复途径
     - 锁定所有遮罩 (`Lock All`)
     - 开机自启设置 (`Launch on Startup`)
     - 退出软件 (`Exit`)

## 5. 边界场景与特殊适配 (Boundary Conditions)

### 5.1 全屏视频播放适配 (Fullscreen Adaptation)
* **问题描述**: 浏览器切换到 HTML5 全屏或操作系统全屏（如 F11 全屏）时，视频窗口可能抢占最高层级，导致普通置顶窗口被覆盖。
* **解决方案要求**:
  * Windows 下使用 `WS_EX_TOPMOST` 窗口样式及对应的顶级层级。
  * macOS 下将 Window Level 设置为 `NSStatusWindowLevel` 或 `NSScreenSaverWindowLevel` 级别的 Overlay，保证全屏下依然稳定置顶。

### 5.2 多显示器与 High DPI 缩放适配
* **问题描述**: 用户在不同 DPI 缩放（如主屏 4K 150%，副屏 1080p 100%）之间拖拽遮罩时，可能出现大小突变或坐标错位。
* **解决方案要求**: 程序声明 `Per-Monitor DPI Aware`（高 DPI 感知），使用物理像素与逻辑像素精准转换。

### 5.3 操作系统权限与安全 (OS Permissions)
* **macOS 权限需求**: macOS 下实现窗口事件穿透与置顶 Overlay，可能需要在“系统设置 -> 隐私与安全性 -> 辅助功能 (Accessibility)”中赋予权限。软件首次启动时需提供友好引导提示。

## 6. 非功能需求 (Non-Functional Requirements)

### 6.1 性能与资源消耗 (Performance)
* **内存占用**: 常驻后台运行时内存占用要求 **< 30MB** (Tauri) 或 **< 80MB** (PyQt6)。
* **CPU 占用**: 后台静止及穿透状态下 CPU 占用接近 **0%**。
* **启动速度**: 软件冷启动时间不超过 **1.0 秒**。

### 6.2 打包与部署 (Deployment)
* **绿化与轻量化**: 提供单文件免安装便携版（Portable），解压即用。
