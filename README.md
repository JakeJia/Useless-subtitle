# Useless Subtitle (字幕遮罩工具)

一款极简、轻量的桌面置顶遮罩工具，专为观看带有多余硬字幕（如视频自带的中文字幕）的视频（Bilibili, YouTube 等）而生。它可以帮你轻松遮挡不需要的字幕部分，还你一个沉浸式的观影和外语学习体验。

## ✨ 核心特性 (Features)

*当前列表为规划中的核心功能：*

- **桌面置顶**：始终悬浮在视频播放器或浏览器网页上方。
- **极简无扰**：纯色或半透明遮罩，无多余 UI 元素。
- **自由调整**：支持鼠标拖拽移动位置和边缘拉伸调整大小。
- **高度自定义**：可自由调节遮罩层的颜色和透明度 (Opacity)。
- **锁定与穿透**：支持“锁定”状态，锁定后鼠标事件将穿透遮罩层，完全不影响底层视频的点击（如暂停、全屏等操作）。
- **状态记忆**：自动记住上次退出时使用的位置、大小和外观设置。
